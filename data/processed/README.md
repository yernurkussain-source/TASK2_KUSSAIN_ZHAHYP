# Processed data

Files here are produced by `python src/process_data.py` (or `src/run_pipeline.py`) and are committed so the analysis runs without downloading the source workbooks. Column definitions are in `docs/DATA_DICTIONARY.md`.

The survey files are derived from Sharma et al. (2026), Mendeley Data V1, https://doi.org/10.17632/88pv88j8jb.1, licensed CC BY 4.0. Cite that dataset when reusing them. They keep only the analysis variables; participant initials, academic-dishonesty items and domicile are not included.
